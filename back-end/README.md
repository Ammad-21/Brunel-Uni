# Spring Boot Backend Learning – Model, Repository, Database Initialization, and H2 Integration

## Overview
This repository demonstrates foundational backend concepts using Spring Boot and Spring Data JPA. The focus is on understanding how entities, repositories, database initialization, and persistence work together, and how to structure a backend for REST APIs. An H2 in-memory database is used for development testing.

---

## 1. Model Layer – User Entity

The `User` class represents a database entity and maps to a `users` table.

**Key Points:**
- `@Entity` and `@Table(name="users")` mark it as persistent.  
- `id` field uses `@Id` and `@GeneratedValue` for automatic primary keys.  
- Fields `name`, `email`, `password` include `@NotBlank` for validation.  
- Getters and setters allow Spring to access and manipulate data.

**Learning Outcome:**  
Understanding entity creation, JPA annotations, ORM mapping, and data validation.

---

## 2. Repository Layer – UserRepository

The `UserRepository` interface provides database access.

**Key Points:**
- Extends `CrudRepository<User, Long>` for automatic CRUD operations:
  - `save()`, `findById()`, `findAll()`, `delete()`  
- Custom query method: `findByEmail(String email)` is auto-generated by Spring Data JPA.  

**Learning Outcome:**  
Learned how Spring abstracts database operations and generates queries automatically, reducing boilerplate SQL code.

---

## 3. Database Initialization – Pre-loading Data

The `DatabaseInitializer` class demonstrates how to execute logic at application startup.

**Key Points:**
- Implements `CommandLineRunner` to run at Spring Boot startup.  
- Uses `UserRepository` to pre-load example `User` records into the database.  
- Ensures the application has initial data for testing and demonstration purposes.

**Learning Outcome:**  
Demonstrates how to automatically populate the database with sample data and understand Spring Boot’s startup hooks.

---

## 4. Database Integration – H2 Testing

An in-memory H2 database is configured for development testing.

**Key Points:**
- Spring Boot auto-configures the database connection.  
- Entity classes automatically generate tables.  
- H2 console used to inspect and verify stored data.  
- Application verified that persistence works correctly.

**Learning Outcome:**  
Demonstrated persistence, table creation, data validation, and query testing without an external database.

---

## Summary

Through implementing the model, repository, database initialization, and H2 testing:

- Learned how entities represent tables and enforce validation  
- Explored Spring Data JPA repositories and automatic query generation  
- Configured database initialization to pre-load example data  
- Verified persistence using H2 in-memory database  
- Gained foundational understanding required for building REST APIs and full backend services
